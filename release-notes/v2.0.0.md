Erste Version des Kotlin-Bots.

## Neu
- Bot komplett in Kotlin neu geschrieben, läuft als ein einzelnes JAR: `java -jar AmongUsManager.jar` (Java 17+).
- Datenbank: SQLite oder MySQL/MariaDB (Panel-Datenbank über `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` in der `.env`). Alte JSON-Daten aus `data/` werden beim ersten Start automatisch übernommen.
- Rollen-Panel (`/rollen-panel`, Admin): Clans, Spiele und Minecraft-Events per Button im Rollen-Channel. Jeder Button zeigt, wie viele die Rolle haben. Pro Person nur ein Clan.
- Auto-Rollen: Jedes Mitglied bekommt die zwei Standard-Rollen automatisch, auch alle, die schon auf dem Server sind.

## Update aufs Panel
1. `AmongUsManager.jar` unten herunterladen und hochladen (das alte ersetzen).
2. `.env` und den Ordner `data/` **nicht** überschreiben.
3. Bot neu starten, danach einmal `/rollen-panel` ausführen.

Die Bot-Rolle muss über allen Rollen stehen, die er vergeben soll.
